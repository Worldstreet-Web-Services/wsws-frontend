# Plan: memecoins on the trade service's frontend contract

Decision: `docs/adr/ADR-2026-09-14-memecoins-trade-contract.md` and its
companion. Status: **not approved yet — do not start.** Each slice is one PR
cut from `origin/staging` in its own worktree, red-green, `./scripts/preflight.sh`
clean, a release note per PR, five locale catalogues per string. Estimates are
engineering hours including tests and review turnaround; they assume the
backend items marked "blocks" are answered before that slice starts.

Ground truth used for the estimates (probed 2026-09-14): the contract's host
`api.worldstreetwebservices.com` does not answer from this machine; the app's
default gateway `api.tsionark.com` serves every route in the contract
(`/tokens` total 100,006; `/portfolio*`, `/activity`, `/swaps` answer 401
without a bearer; gas-sponsor `configured: true`, sponsor wallet 0.0623 SOL).

## Contracts

- Identity is `chainId + address` on every request and in every key; a Solana
  address is compared as written.
- `limit` is never above 500 on `/tokens`, 100 on `/portfolio` and
  `/activity`; the client stops at `page * limit >= total`.
- No quote is requested for a `LOW_LIQUIDITY` token before the consent dialog
  is accepted in this session; `BLOCKED`, `buyEnabled: false`,
  `sellEnabled: false` and a server error are the only things that disable
  the action.
- `confirmed` is set only on status `CONFIRMED`; on-chain proof without it is
  `delivered`; a poll past the ceiling is `pending`. All three keep `swapId`
  and `requestId` in logs and on screen.
- The fee shown is the preview's or quote's; nothing hard-codes the rate.
- Solana: prepare (fee payer rewritten) → user signs → sponsor submits; the
  signed transaction is never modified; the sponsor's `submittedSignature` is
  what gets registered.
- Money and quantities are decimal strings end to end; display formatting is
  the only place a number is produced, and never for a null.
- Every relayed route is validated at `app/api/trade/[...path]/route.ts`;
  a shape drift is a 502 with a `requestId`, never a crash in a component.
