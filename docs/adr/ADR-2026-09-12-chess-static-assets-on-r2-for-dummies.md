# ADR For Dummies: Put Heavy Chess Files On R2

- Status: Proposed
- Date: 2026-09-12

## The Problem

The frontend repository contains large chess files that are not source code. Voice recognition models, chess engines, images, sound packs, and optional themes make the repository and deployments much larger than necessary.

## The Decision

We will upload those large files to Cloudflare R2 and let the browser download them only when a chess feature needs them.

The TypeScript and React code stays in the frontend repository. Small files needed to start the chess UI also stay local. Large engines, voice models, media, and optional packs move to R2.

Every uploaded file keeps a predictable path under a versioned `chess-assets/v1` folder. Existing chess links continue to work, including old paths generated by copied Lichess code.

## What Users Will Notice

The chess UI and flow should not change. The first use of voice recognition or a computer engine may download a large file from R2, then the browser cache reuses it. Normal pages no longer ship all optional chess files as part of the application deployment.

## What Developers Will Notice

- Frontend clones, CI jobs, and deployments carry much less chess data.
- A script uploads changed chess assets and verifies them.
- A manifest records exactly what R2 must contain.
- Only the public R2 address is used by browser code.
- The R2 access key and secret stay in ignored `.env` files or the deployment secret manager.

## Safety

We upload and verify every file before deleting its local copy. Files use versioned paths, so a new release cannot silently replace bytes cached by an older release. If anything fails, we can point the application back to an older asset version or restore the local files.

The setup credentials must be rotated after this work because they were shared outside the secret manager. They will not be committed.

## Definition Of Done

Chess still supports computer play, voice input, sounds, pieces, puzzles, analysis, and spectator pages. A fresh production build passes without the removed files, and the chess assets left in Git are targeted below 10 MB.
